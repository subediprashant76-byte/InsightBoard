# InsightBoard

A sales dashboard built with React and Recharts.

## Features

- Revenue line chart, orders by category bar chart and traffic source pie chart
- Date range filter (7, 30 or 90 days)
- Summary cards that compare the two halves of the selected period
- Collapsible sidebar

The data is generated in `src/data.js`. Replace `fetchStats` with a real API call to use your own data.

## Run it

```
npm install
npm run dev
```
